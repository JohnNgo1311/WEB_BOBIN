JS Form (extrusionView.php)
    ↓ submit.js sends AJAX POST
BobinController
    ↓ receives request
BobinCreateDTO (raw input: string)
    ↓ BobinService validates & converts
Bobin Entity (DateTime, objects)
    ↓ BobinRepository processes
Database (MySQL storage)


┌─────────────────────────────────────────────────────────────┐
│                    DETAILED WORKFLOW                         │
└─────────────────────────────────────────────────────────────┘

1️⃣  JS FORM
    └─ User submits from extrusionView.php
    └─ submit.js sends AJAX POST → index.php?url=bobin/createBobin

2️⃣  BOBIN CONTROLLER
    └─ Receives HTTP request
    └─ Calls BobinCreateDTO::fromRequest($_POST)
    └─ Passes DTO to BobinService

3️⃣  BOBIN SERVICE
    └─ Validates input (e.g., bobin code required)
    └─ Converts IDs → Objects (Employee, Product)
    └─ Creates BobinEntity (standardized object)
    └─ Calls BobinRepository→save($entity)

4️⃣  BOBIN REPOSITORY
    └─ Receives Entity
    └─ Converts nested objects (VisualInspection, Employee) → JSON
    └─ Executes INSERT INTO MySQL

5️⃣  DATABASE
    └─ Stores data

6️⃣  RESPONSE FLOW
    └─ Service returns Entity → Controller
    └─ Controller returns JSON → JS
    └─ Toast.show() displays success message

📝 Giải thích luồng dữ liệu đi qua các thư mục
Để bạn dễ hình dung cách code chạy qua các thư mục này:

Frontend (public/assets/js/Extrusion/submit.js):

Người dùng bấm "Lưu". JS gom dữ liệu gửi POST về Server.

Controller (app/controllers/BobinController.php):

Nhận request.

Gọi app/dtos/BobinCreateDTO.php để đóng gói $_POST thành một object gọn gàng.

Service (app/services/BobinService.php):

Controller chuyển DTO sang cho Service.

Service kiểm tra logic (ví dụ: mã bobin có trùng không, nhân viên có tồn tại trong app/models/ không).

Service tạo ra một app/entities/BobinEntity.php.

Repository (app/repositories/BobinRepository.php):

Service chuyển Entity sang cho Repository.

Repository viết câu lệnh SQL (INSERT INTO...) để lưu vào Database.
